# ECode 活文档清单与同步守则

> 日期：2026-08-16 · 动机：功能演进时提示词与文档容易漏更新（"文跟不上更新内容"）——
> M8 复盘确认了真实漂移（system prompt 工具指引缺 Skill/ask_user/web_fetch；CONFIG_TEMPLATE 缺 M7 hooks 与 M8 三个配置键）。
> 三层防线：**本清单（人查）+ 防漂移测试（程序断言，最硬）+ /doctor 抽查（LLM 核对）**。

## 四、三层防线

1. **防漂移测试（最硬，机器执行）**：`tests/core/system.test.ts` 断言——builtin 工具集的每个工具名都被 buildSystemPrompt 输出覆盖（新工具注册但指引没写 → 测试红）。目前覆盖第 1 项（漂移风险最高的单点）；config 模板与内置手册的键一致性暂靠 LLM 抽查。
2. **/doctor 抽查（LLM 核对）**：DOCTOR_PROMPT 第 7 项——按本清单抽查高漂移点（config.json 实际可用键 vs CONFIG_TEMPLATE 注释 vs ecode-config 手册；system 工具指引 vs /help 命令表）。
3. **本清单（人查）**：动功能前扫一眼"同步触发"列——**改到左边就该查右边**。

## 五、流程约定（并入 AGENTS 工作流）

- 新增工具 → 必改：system.ts 指引（测试逼你）+ 工具 description + ecode-config 手册（若涉及配置）+ CONFIG_TEMPLATE（若加 config 键）。
- 新增斜杠命令 → 必改：registry description；涉及新交互面 → TUI 规范。
- 里程碑收尾 → 必改：方案文档 status+实施记录、AGENTS 状态行、README 索引（三件套）。
- 忘了任何一条 → `/doctor` 或角色审阅兜底；测试锁定的部分根本忘不掉。
