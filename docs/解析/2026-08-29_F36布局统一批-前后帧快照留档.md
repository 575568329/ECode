## 规则清单（CC 源码实证 + 网上互证，实施依据）

CC（`claude-code-main`）：左轨双槽——圆点槽 `minWidth={2}`（⏺/●/spinner）、⎿ 槽 5 列（`"  ⎿  "` flexShrink=0）；正文列 flex 吃剩余宽，折行宽=正文 Box 内容宽，续行落第 2 列（布局副产品，非拼空格）；assistant 文本/流式/系统行全走圆点槽；用户消息例外（整块背景+行内 ❯）；嵌套 ⎿ 用 Context 抑制。槽宽数值在 CC 是散落魔法数字（三处注释互证），ECode 收口 `layout.ts`。

网上互证：每条 assistant 消息/工具调用一个 ⏺、工具结果 ⎿ 缩进于所属调用下、换行器「indents continuations to line up under the ⏺」（Trevor Fox 复制结构分析）；agent TUI 惯例=窄左列 ✓/✗ 图标+左对齐正文（awesome-tui-design spec）。

```diff
-

+ ● 助手回答段落一。      ← 圆点槽 2 列 + 正文列
+
+   段落二。              ← 折行续行对齐第 2 列（悬挂缩进）
```
