## 二、P0（TUI 渲染，全部坐实，修复批 1）

### P0-1 alt 全屏帧高账本多处漏行 → 帧高 ≥ rows 触发每帧全清/退出抹 scrollback
- OutputViewer.tsx:384 alt 高度 `rows−6`：面板 chrome 5 行 + 搜索行 1 = 帧高恰 `rows`（开搜索即触发 win32 每帧 clearTerminal；注释自称「恒 rows−2」与公式不符）。
- App.tsx:155 warning 行在 `!altMode` 闸门之外；Conversation.tsx:225 children（SubagentBar/TasksBar/ErrorBanner）与 TuiApp systemMsgs 均不受 altMode 收口——busy 中 Ctrl+T 看子代理（SubagentBar 活着）帧高 ≈ rows+2。
- **修法**：alt 高度改 `rows−7`；warning/banner 由 App 按 altMode 收口；children/systemMsgs 由 TuiApp 按 altActive 收口。

### P0-2 TodoPanel（≤14 行）未入 allocateDynamic 总守卫 → 常态超预算
- TodoPanel.tsx MAX_VISIBLE=12+表头+溢出提示最多 14 行；viewport.ts allocateDynamic 的 CHROME_RESERVE/USER_INPUT_LINES 均无 todo 项。24 行终端叠 12 项清单 ≈ 36 行 >> budget → overflow 3J（0b60219 晚于 overscreen 探针，未被覆盖）。
- **修法**：conditions 扩 `todoLines`（TuiApp useMemo 派生行数传入 allocateDynamic）；TodoPanel 支持 maxVisible 收口；退化态隐藏。

### P0-3 审批/askUser 强制退面板绕过 closeOutputPanel → altActiveRef 卡死吞后续全部 commit
- TuiApp.tsx:540 `approval/requested` 只 setOverlay(null)，不复位 altActiveRef、不 flush pendingCommittedRef → 此后每个 turn/completed 的 setCommitted 永久进暂存，主界面对话静默停更；askUser/requested（592）同病（直接覆盖 overlay）。另 1049l 由 AltScreen 卸载 cleanup 补写（提交后晚写），恢复主树首帧有画进 alt buffer 的时序窗口。
- **修法**：抽 teardownAltFrame()（exitAltScreen 同步写 + altActiveRef=false + flush）；审批/askUser 强制退面板统一走它。

### P0-4 ECODE_NO_ALT_SCREEN/tmux 降级链双重失效
- TuiApp.tsx:1131 `altActive` 计算不含 noAlt → 降级时 altContent 恒非 undefined，嵌入式降级分支（1341/1367）是死代码；且 `<AltScreen/>` 照样挂载，useInsertionEffect 见模块 flag 为 false 即补写 ENTER——降级模式照样进 alt buffer 且是提交后晚写。
- **修法**：模块级 NO_ALT 判定；altActive 计算纳入；降级时走嵌入式分支（面板功能可用观感降级的原设计）。
