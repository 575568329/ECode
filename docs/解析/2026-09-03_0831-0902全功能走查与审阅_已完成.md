1. **closeDeadTurn updater 副作用外提（真 bug）**——审批 resolve+note 原写在 setState updater 内，React 延迟执行时调用方同步读到的 notes 为空：「挂起的审批已随轮作废」提示**静默丢失**。测试席的审批作废覆盖锁（本批新增）直接抓出，帧级时序复现（t=8s 收场、note 永不出现）。修复：闭包态同步 resolve+记 note，updater 内只留同拍新到审批的对象身份兜底。

4. **W-9 运行态对账**——gap 重连只补 transcript 不对账 busy：断线窗口的 turn/completed 帧永久丢失时 TUI 恒假忙碌（SSE 已 open，G3 tick 只认非 open 永不再自愈）。修复：gap 时 session/list 的 running 注入对账（明确 not running 即 closeDeadTurn 同款收场，经 ref 桥取最新闭包）。
