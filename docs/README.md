## 命名规则

1. **里程碑三件套**：`MX-{类型}.md`（类型 ∈ 技术选型与理由 | 实施方案 | 方案解析），放 `里程碑/`。
2. **一次性文档**：`YYYYMMDDHHMMSS_标题-分类后缀.md`，后缀 `-详设` / `-调研` / `-诊断` 决定归属目录。
3. **跨文档引用**用相对路径；**重命名/移动文件必须全量 grep 改链接**。
4. **实现状态后缀**（文件名一眼看出进度，不用打开文档猜）：
   - `[已完成]` — 文档描述的功能已全部在 `src/` 中实现 + 测试通过
   - `[进行中]` — 部分实现（有代码但不完整，或只完成了文档描述的一部分）
   - `[待实现]` — 纯设计文档，代码尚未开工
   - `[已归档]` — 诊断类文档，问题已修复、经验已沉淀到 debugging.md
   - 功能完整落地后**去掉后缀**（恢复为普通文件名）
