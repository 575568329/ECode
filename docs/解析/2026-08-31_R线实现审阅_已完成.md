## 二、P0（已修，含回归锁）

**[P0-1] relay/server.cjs `/v1/hosts/online` 一击崩进程**（架构席实跑复现 + 安全席独立复现）
`res.writeHead(200)` 之后 `res.setHeader('cache-control')` → Node v22 抛 ERR_HTTP_HEADERS_SENT，handler 无兜底 → 进程退出。DevicesPanel 每 15s 轮询此端点=部署后第一次打开设备面板即自杀，且是共享 relay（所有主机隧道同刻全断）。
**修**：cache-control 并入 writeHead 对象。**回归锁**：relay-hardening.test.ts「hosts.online 正常回显+进程仍存活」。

**[P0-2] phoneConnectUrl 缺省派生死链**（架构/开发/测试三席独立确认）
serveMain 缺省 `hostBase=server+'/ecode-tunnel'`，而 phoneConnectUrl 回退 `hostBase+'/ecode'` → 拼 `wss://host/ecode-tunnel/ecode/v1/connect/x` → 命中电脑段 404。自部署指南 §3 示例 config 只配 server——照文档部署每张二维码都连不上。测试与探针全部**显式传 phoneBase**，恰好掩盖缺省路径（盲区结构典型样本）。
**修**：serveMain 显式 `phoneBase = config.relay.phoneBase ?? server+'/ecode'`；relayClient 无 phoneBase 时 throw（拒绝静默死链派生——本地双端口/双前缀下二者无派生关系）。**回归锁**：relay-hardening.test.ts「显式正常拼装/缺省必须 throw」。
