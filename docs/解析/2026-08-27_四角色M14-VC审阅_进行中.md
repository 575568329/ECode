- **P2-6** mux baseline 的 acquire(entry.path,{confirm:true}) 绕过凭据分级语义（当前仅遍历已活项目无现实绕过）。建议 confirm:false 依赖 live 复用。
- **P2-7** 401 无失败速率限制：LAN 弱口令暴破面。建议非 loopback 逐 IP 退避。
- **P2-8** asker 键控挂载面核实：仅本进程 mountBridges/dispose 调用，dispatch 命令面无触达 op——攻击者无法经 HTTP 预挂/伪造 asker，键可猜测性无实际意义。**未发现可利用面 ✓**。

### 分区结论（10 维度核实表）

| 维度 | 结论 |
|---|---|
| 凭据 | digest 等长 ✓ / Bearer-only ✓ / 不短路 ✓ / tie 方向安全但未文档化 / hasPrimary 死代码 |
