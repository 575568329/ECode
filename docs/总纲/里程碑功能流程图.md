## ③ Agent Loop 运行时流程(项目心脏,M1 产物)

> 贯穿所有阶段的核心机制。**硬约束**:`tool_result.tool_use_id == tool_use.id`(不配对 → API 400);`messages` 累加不重建;M3 压缩绝不能破坏 id 配对。

```mermaid
flowchart TD
    Start([task 任务]) --> Init["runAgent()<br/>init messages · 选 Provider · 选工具集"]
    Init --> Loop{"iteration ≤ 25?"}

    Loop -- 否 --> Max([⚠ 达最大迭代终止])
    Loop -- 是 --> Call["Provider.complete()<br/>withRetry: 429/529/500 退避重试"]
    Call --> Parse["解析 content 块<br/>(ECode 统一格式)"]
    Parse --> HasTool{"有 tool_call?"}

    HasTool -- "否(纯 text)" --> End([break · 输出最终回答])
    HasTool -- 是 --> Exec["executeTool()<br/>read/write/edit/grep/glob/bash"]
    Exec --> Push["push tool_result<br/>⚠ id 必须配对 tool_use.id"]
    Push --> Check{"连续重复签名?"}

    Check -- 否 --> Loop
    Check -- 是 --> Warn([⚠ 死循环检测终止])
```
