## 五维落点对照

| 维度 | 改动 |
|---|---|
| ① 缩进栅格 | `INDENT.gutter=5`（"  ⎿  "）+ 工具行缩进 0（砍 paddingLeft=3）；INDENT.icon=2 锁宽 |
| ② 块间距 | `GAP.block=1` 统一（ToolGroupView 上下 margin / Markdown 块 gap / UserMessage 上 margin）；FoldedUserInput 砍双倍 marginTop；space token 零渲染 |
| ③ 视觉层级 | 工具名 dim → bold（ToolGroupView）；gutter/元信息保持 dim |
| ④ 悬挂缩进 | Gutter() 组件 + 内容列结构：输出/diff/preview/折叠提示/todo 项全走 gutter；wrap 宽 `WIDTH.toolOutput`（columns−10）约束内容列，续行对齐 ⎿ 下方 |
| ⑤ 宽度公式 | `WIDTH.content=min(cols,100)` / `WIDTH.toolOutput=cols−10` / `WIDTH.toolNames=cols−14` 一处定义（layout.ts），三处引用收敛 |
