## 命名规则

1. **里程碑三件套**：`MX-{类型}.md`（类型 ∈ 技术选型与理由 | 实施方案 | 方案解析），放 `里程碑/`。
2. **一次性文档**：`YYYYMMDDHHMMSS_标题-分类后缀.md`，后缀 `-详设` / `-调研` / `-诊断` 决定归属目录。
3. **跨文档引用**用相对路径；**重命名/移动文件必须全量 grep 改链接**。

## 维护协议

- 新增长文前先问：能否并入已有里程碑文档？避免 notes 泛滥。
- 新增后**立即**在本 README 对应分类追加一行。
- 月度回顾时同步删除已并入/废弃的条目。
