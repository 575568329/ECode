## 二、文件内容详解

### 2.1 package.json

```json
{
  "name": "ecode",
  "version": "0.1.0",
  "type": "module",
  "description": "手写 AI coding agent - 学习型项目",
  "main": "dist/index.js",
  "bin": {
    "ecode": "dist/index.js"
  },
  "scripts": {
    "dev": "tsx src/index.ts",
    "build": "tsc",
    "start": "node dist/index.js",
    "test": "vitest"
  },
  "keywords": ["ai", "agent", "coding-assistant", "llm"],
  "author": "fjyu9",
  "license": "MIT",
  "dependencies": {
    "@anthropic-ai/sdk": "^0.32.1"
  },
  "devDependencies": {
    "tsx": "^4.19.2",
    "typescript": "^5.7.2",
    "vitest": "^2.1.8"
  },
  "engines": {
    "node": ">=18.0.0"
  }
}
```

**关键字段说明**:
- `"type": "module"` — 启用 ESM，让 `import/export` 生效
- `"bin": { "ecode": "..." }` — 将来 `npm i -g` 后可以全局用 `ecode` 命令
- `scripts`:
  - `dev` — 开发时用 `tsx` 直跑 TS，改完即测
  - `build` — 发布前编译成纯 JS 到 `dist/`
  - `start` — 跑编译后的 JS（生产环境）
  - `test` — 跑 Vitest（M1 末尾或 M3 真写测试时用）
- **依赖版本号**:
  - `@anthropic-ai/sdk` 用 `^0.32.1`（当前最新稳定版，2026-07）
  - `tsx` / `typescript` / `vitest` 用最新稳定版

### 2.2 tsconfig.json

```json
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "NodeNext",
    "moduleResolution": "NodeNext",
    "lib": ["ES2022"],
    "outDir": "./dist",
    "rootDir": "./src",
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true,
    "forceConsistentCasingInFileNames": true,
    "resolveJsonModule": true,
    "declaration": true,
    "declarationMap": true,
    "sourceMap": true,
    "noUnusedLocals": true,
    "noUnusedParameters": true,
    "noImplicitReturns": true,
    "noFallthroughCasesInSwitch": true
  },
  "include": ["src/**/*"],
  "exclude": ["node_modules", "dist"]
}
```

**关键配置说明**:
- `"module": "NodeNext"` — TS 官方的 ESM + Node.js 混合方案，支持 `.js` 扩展名、条件导出
- `"strict": true` — 开启所有严格检查（符合 CLAUDE.md 规范）
- `"noUnusedLocals"` / `"noUnusedParameters"` — 代码质量约束（学习项目要求干净）
- `"sourceMap": true` — 调试时能映射回 TS 源码（`tsx` 需要）
- `"declaration": true` — 生成 `.d.ts` 类型定义文件（将来发 npm 包需要）
