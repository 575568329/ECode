## 3. 批1：复测裁决 + 探针升级 + 两小修（建议 ≈1 人天）

### 3.1 探针升级（本批核心交付，先行）

现状缺口：`scripts/pty-wedge-probe.cjs` 的调度活性判定=**stdin 回显**，半活态下回显活但功能键死——**探针全过 ≠ 没楔死**。

新增 `scripts/pty-semialive-probe.cjs`（或并入现有探针作第二判定组）：

1. **Enter 提交探针（不烧 token 设计）**：轮末写 `/stats` + `\r`，判定任一预期帧出现：
   - 统计输出出现（Enter 生效、命令执行）；
   - 或忙碌拦截提示出现（InputStream.tsx:152 `onSlashBusy` 分支——Enter 生效、被分流）。
   - 两者皆无且超时 → **半活实锤**（Enter 未被处理）。
2. **Ctrl+C 语义探针**：空闲态双击 Ctrl+C（9ad1a83 语义：优雅退出），判定进程在 N 秒内退出；不退 → 键消费死。
3. **场景矩阵**（每场景后跑 1+2）：
   - S1 纯文本轮 ×3（对齐现有 wedge 探针）；
   - S2 **本地命令轮**：发 `/stats` → 等输出 → 探针（dogfood 卡死场景首次进探针覆盖）；
   - S3 工具轮：mock SSE 带 tool_use/tool_result 往返（注意挂账坑「loop 要求工具调用但未给出工具」——mock 必须带 tools 定义）。
4. 判定输出：每场景 `OK/FAIL` 一行 + FAIL 时末 20 帧 + CPU 差分留痕（沿用现有探针取证格式）。

### 3.2 复测裁决流程

1. `npm run build`（tsc 产出新 dist；**不重启任何运行中进程**，Windows 下已加载的 js 可安全覆盖）；
2. 外部驱动侧跑升级探针（新 dist）：S1-S3 全过 → **F-08 销案**（销案记录回填挂账 memory），探针入库防回归；
3. 任一场景 FAIL → F-08 转入实修，按机理定位修：
   - 机理 A（running 卡 true）：TuiApp 终局事件兜底复位（`turn/completed`/`error` 均解除 busy，不单依赖 thread/status）+ `session.ts` 审查 busy:true 发送点（:620/:682）与 finishTurn（:790）严格配对（dev 断言）；
   - 机理 B（面板吃键）：复核 /stats 输出路径是否 setOverlay/面板态（commands/registry action 枚举现无面板项，倾向排除，以复测为准）；
   - 修复后同矩阵复测全过才关单。

### 3.3 F-01 CLI 参数校验（确定性修）

`src/cli/index.ts` 入口（:110 前插解析层）：
- `-v`/`--version` → 输出 `package.json` version，exit 0（不进 LLM）；
- `-h`/`--help` → usage（REPL/单次/serve 三形态一行式），exit 0；
- 其余 `-` 开头 token → stderr `未知参数: xxx` + usage，exit 1；
- `serve` 子命令族不变；非 `-` 开头参数继续走 argv 单次模式（保留脚本/管道用法）。
- 测试：三 flag 路径 + 未知 flag 拒绝 + 无参进 REPL（现有行为回归）。

### 3.4 F-05 diff 文件名转义（确定性修）

`src/tools/builtin/edit_file.ts:104`：`createTwoFilesPatch` 对非 ASCII 文件名生成 `"\350\257\246..."` 八进制转义 header。修：patch 生成后对 `---`/`+++` 两行 header 做八进制序列解码还原（执行时先读 jsdiff 转义实现确认编码形态，宁可 unit test 锁行为）；`write_file.ts` 同款检查。测试：中文路径文件 diff 输出含可读文件名。
