## 5. 已知限制（M2 范围外）
- Ink 7 无鼠标 API（#765 non-goal）→ follow 滚动靠终端原生 scrollback + 键盘
- 非 alt screen → StatusBar 不能常驻最顶（在底行）
- 发布版（npm i -g）无 cross-env，punycode warning + 高亮会重现（发布前处理）
- **Ink Static + resize/滚动风险**（待真终端验，用户反馈问题 2/3）：resize 窗口或滚轮可能触发
  Static 渲染异常（内容消失/上一轮重复）。已修 /clear remount（clearKey）+ items useMemo；
  若真终端仍 bug，候选方案：① 不用 Static（消息全动态区，性能换稳定）② 自建 OffscreenFreeze
  （Claude Code 式，M3+）。这是 stock Ink Static 的已知弱点（Claude Code 因此弃用自建）
- **流式期滚轮被拉视角**（问题 2）：非 alt screen 下 Ink 动态区每帧重绘，用户上滚看历史会被
  下一 token 拉回。Ink 限制，alt screen 自建滚动可解（大工程，M3+）
